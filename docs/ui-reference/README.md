# UI reference (pointer)

The reference UI captures are **not committed** to frost — they are screenshots of a third-party
product's UI, kept out for clean-room and IP hygiene. They live in the private analysis workspace
on the origin host (**a Mac**):

    <private workspace>

Contents: 28 PNGs + `_contact_sheet.html` (a labeled grid). Ask the origin-host session to stage
them somewhere private if you need them on this host.

## Surfaces captured (for direction, not duplication)
- **Shell:** default 3-pane layout (left rail · SEO sidebar · browser · AI chat).
- **SEO panels:** Overview; On-Page (Content/Links/Images/Social); Indexability; AI readiness;
  Schema; Page Speed; Compliance; JavaScript; Search Console; Changes.
- **App views:** Projects, Screenshots.
- **Settings:** Profile, Teams, Preferences, Browser, General, People, Integrations, Billing, API keys.

## Direction (how frost should improve on the reference)
- Make the AI panel summonable and the SEO sidebar collapsible, so the page gets room by default.
- Replace the hidden panel dropdown with a persistent, scannable rail showing per-panel status
  (pass / warn / error) at a glance.
- Build every panel around the Overview pattern: health score → ranked issues → fix.
- Settings is a keep-and-refine, not a rethink.
